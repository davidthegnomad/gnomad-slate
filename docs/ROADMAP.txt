ROADMAP — GNOMAD SLATE
======================

Version: 0.1.0 · Last updated: June 2026

────────────────────────────────────────

COMPLETED (V0.1.0)
------------------

  • Vault-X with Argon2id + AES-256-GCM v2
  • Rust-only secrets + heap zeroization
  • Unlock rate limiting
  • Clipboard filter (entropy + blocklist) + sidebar toggle
  • macOS pasteboard changeCount + adaptive polling
  • Markdown Edit / Split / Preview
  • 14 Rust + 4 Vitest tests
  • Full documentation suite
