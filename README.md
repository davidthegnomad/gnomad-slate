# Gnomad Slate

Desktop scratchpad and vault for Gnomad Studio — built with **Tauri 2**, **React**, and **TypeScript**.

## Features

- Ephemeral scratch notes and persistent vault notes
- Clipboard history capsule
- Encrypted secrets storage
- Global shortcuts and command palette

## Development

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```

## Stack

- Frontend: React 19 + Vite
- Desktop: Tauri 2 (Rust)
